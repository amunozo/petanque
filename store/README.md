# Store listing + app icon assets

Everything here (and in `public/icons/`) is generated by scripts in `art/branding/` (Blender via
`bpy` + Pillow), so it can be regenerated after a change. Look: natural, realistic-leaning colours
(sun-warmed terracotta gravel, polished steel boules with a faint blue / bronze team tint, the
yellow jack), high contrast so the icon reads at 48 px. Fonts are the game's own Fredoka (logotype)
and Nunito (tagline), read from `public/fonts/`.

## Colours

| Use | Colour | Notes |
| --- | --- | --- |
| Icon background (adaptive-icon background, Bubblewrap `backgroundColor` for icons) | `#a95f3a` | mid tone of the icon's gravel ground |
| Splash background (TWA splash / manifest `background_color`) | `#a95f3a` | same as the icon, so icon -> splash -> game feels continuous |
| Theme / status bar (suggestion) | `#a95f3a` or a darker `#7f4226` | the manifest currently says `#2a3550` (navy); player's call |
| Logotype extrusion (feature graphic) | `#b5532c` | terracotta, close to the UI's `--terracotta` |

## Regenerate

```sh
art/.venv/bin/python -m pip install -r art/branding/requirements.txt   # once: Pillow, fontTools, brotli
art/.venv/bin/python art/branding/icon.py             # all icons + adaptive + splash (~10 min: 2 Cycles renders)
art/.venv/bin/python art/branding/icon.py --reuse     # recompose only (framing, colours, vectors) - seconds
art/.venv/bin/python art/branding/feature.py          # feature graphic (~10-15 min, 2x render + downsample)
art/.venv/bin/python art/branding/feature.py --preview  # quick low-res check (written to $TMPDIR/petanque-branding/)
art/.venv/bin/python art/branding/feature.py --reuse  # re-letter the cached render only
art/.venv/bin/python art/branding/review.py out.png   # contact sheet of the icons at real sizes (48-128 px, masks)
```

Renders are cached in `$TMPDIR/petanque-branding/`. The scenes:

- `art/branding/icon_scene.py`: the icon scene (ball layout, colours, camera). Framing per output
  (`FILL_*`), corner radius and brand colours are constants at the top of `icon.py`.
- `art/branding/feature_scene.py`: the feature-graphic square (own simplified village: facades,
  plane trees, café awning, court), low camera with depth of field and a motion-blurred boule in
  flight. It does not load the game's scenery models, so it is stable while those change.
- `art/branding/stage.py`: shared Blender helpers (world, sun, camera, steel boule / jack
  materials, faceted gravel); `imaging.py`: Pillow helpers (fonts from `public/fonts`, masks).
